이 이미지는 래스터(사진·스캔) 차트를 2~3배 확대한 crop이다. 값을 한 번에 어림잡지 말고 아래 순서를 그대로 따라라.
1단계: y축의 눈금 숫자와 그 숫자가 적힌 가로 격자선(또는 눈금 표시)의 세로 픽셀 위치를 전부 읽어라(최소 2개).
2단계: 막대 꼭대기·점·선의 위치를 1단계 눈금들 사이의 비율로 나타내라(두 눈금 사이 몇 %에 있는지).
3단계: 그 비율을 눈금 값 사이에서 선형(또는 로그, 눈금이 10의 거듭제곱이면) 보간해 실제 값으로 바꿔라.
JSON 하나만 출력: {"y_ticks": [{"value": 0, "y_px": 0}], "log_axis": false, "items": [{"x": "", "series": null, "top_px": 0, "unit": null}]}.
y_px·top_px는 이 이미지(확대된 crop) 안의 세로 픽셀 좌표. 확신 없는 항목은 넣지 말아라(추측 금지).
