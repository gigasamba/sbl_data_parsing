파이프라인 문항 탐색기

평가에 쓴 문항을 한 줄씩 봅니다. 질문(검색 앵커 또는 파싱 QA 항목), 정답, 그리고 파서·조합(스택)별로 맞혔는지(✓/△/✗)를 나란히 보여 줍니다. 행을 누르면 파서별 실제 출력, 조합별 검색 상위 결과(LLM에 넘길 글), LLM 답이 펼쳐집니다. 실패가 많은 문항이 위로 정렬되고, 표 머리의 이름을 누르면 그 파서·조합이 실패한 문항만 남습니다. 데이터는 도구가 만든 파일에서 자동으로 채워지므로 문서가 바뀌어도 같은 구성으로 다시 만들어집니다.

세 가지 측정

  • 파싱 QA(LLM 0회): 문서의 정답 값(숫자·날짜·ID·라벨 값)이 파서 출력에 있는가. 행 = 값 하나, 열 = 파서.
  • 검색 근거(LLM 0회): 값을 뺀 질의로 검색했을 때 상위 5개 안에 그 문서의 그 값을 담은 조각이 있으면 ✓, 6~10위면 △, 없으면 ✗. 근거가 없으면 LLM은 맞힐 수 없습니다.
  • 답변 정답(LLM 사용, 서버): 상위 조합의 컨텍스트로 GLM이 답한 값이 정답과 같은가. 아쉬움 △는 점수 없이 따로 셉니다.
  • 정답의 출처: truth = 가상 문서 정답 · answer_key = 사람 정답지 · native = 텍스트형 원본 · consensus = 인식 계열 3개 이상 합의(은, silver).
