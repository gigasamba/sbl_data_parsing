### 임베딩 병렬화

- "embed model 호출할 때, chunk batch 32 개씩 묶어서 호출. 병렬 호출은 문서당 4개까지 허용"
- "여기서 스레드 1개로 하고 문서 경계 없이 할 것 같아"

### 문서별 flow 전환
- "지금 단계에서, 배치를 하게 되면 다른 문서 끝날때까지 기다리게 되니까 queue 관리를 하게 하면 좋겠어"
- "1) 대상 문서 대기 (최대 12개 까지만 미리 다운로드, 하나 parsing 시작하면 다음 것 다운로드, 즉 대기열 문서가 12개 유지 + 진행중인 것은 count 제외 + 종료되면 tmp 폴더에서 삭제"
- "2) 문서별 flow 진행. 그 과정에서 하나의 문서에서 나온 image 나 ocr 처리는 병렬로 수행 가능. 문서별 병렬 허용은 vlm 호출 4회, ocr 호출 1회, vlm_page 기능은 off, rapid_ocr_ko 등에서 dpi 는 150 설정"
- "3) 문서 개별 단위로 구조화+적재 수행. 이 과정에서 embed 호출도 batch 12개로 나눠서 호출 가능. 병렬 호출 문서당 4개 까지 허용. bm25 수행도 문서당 4개 까지 병렬로 수행 가능 허용."
