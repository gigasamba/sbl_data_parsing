# 서버·사람이 확인해야 할 사항(C)

저장소 안에서 끝낼 수 없는 확인(서버에서 볼 것, 다른 담당자와 협의할 것, 사용자가 정할 것) 중 **열린 것만** 둔다. 끝나면 줄을 지운다(이력은 git). 0.2.0 배포의 사람 할 일 순서는 [release-and-patch.md §8](../operations/release-and-patch.md#8-020-배포--사람이-할-일)이 정본이고, 이 표는 항목별로 무엇을 돌리고 무엇이 통과인지 적는다.

- 새 항목은 다음 번호(`C-xx`)로 덧붙인다. 번호는 다시 쓰지 않는다. "누가"는 역할로 적는다.
- 비밀값·접속 값은 이 문서에 쓰지 않는다.
